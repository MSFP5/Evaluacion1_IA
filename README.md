# Evaluacion1_IA
## Descripcion del Proyecto
**Soluciones IA** es un sistema de inteligencia artificial diseñado para **automatizar y optimizar la atención al cliente de Petco**. Utiliza una arquitectura avanzada de **Generación Aumentada por Recuperación (RAG)** para proporcionar **respuestas instantáneas y precisas**, basándose en una base de conocimientos interna sobre productos y servicios.

## Contexto  
**Petco** es una empresa especializada en productos y servicios para mascotas, con presencia en Chile y otros países. Su objetivo es ofrecer soluciones integrales para el bienestar animal, incluyendo alimentos, accesorios, medicamentos y servicios veterinarios.  

La visión de Petco es consolidarse como la tienda líder en cuidado de mascotas, brindando experiencias de compra personalizadas y apoyo continuo a los tutores responsables.  

## Problemática  
Actualmente, Petco enfrenta un desafío en la **atención al cliente**:  
- El alto volumen de consultas frecuentes (sobre alimentos, salud y productos) supera la capacidad del personal.  
- Los tiempos de respuesta generan demoras en la resolución de dudas de nuevos clientes.  

## Nuestra Propuesta 
**Soluciones IA** es un sistema de inteligencia artificial diseñado para **automatizar y optimizar la atención al cliente de Petco**. Utiliza una arquitectura avanzada de **Generación Aumentada por Recuperación (RAG)** para proporcionar **respuestas instantáneas y precisas**, basándose en una base de conocimientos interna sobre productos y servicios.

Esto permite ofrecer **respuestas automáticas, rápidas y precisas**, mejorando la experiencia del cliente y optimizando la carga del equipo de soporte.  

## Antes de Instalar  
Asegúrate de tener configurados los tokens de **GitHub** y **OpenAI** en el archivo `.env`, siguiendo el ejemplo en `.env1.example`.  

El proyecto está configurado para usar **gpt-4o**.
Para iniciarlo copiar: streamlit run evaluacion.py
